Icon coverage and contrast were checked locally. ## Exact designs for the two owner requests

**Many tabs (R02).** Support the existing maximum of 20 canvases and 40-character names (`src/state/document.ts:13–14`). Keep canvas tabs distinct from the Figure page command; “Figures” is an ordinary user tab, not a second publication workspace.

Use a tab region with a **420px minimum budget**, independent of toolbar intrinsic width. Its scrollable tablist has nonshrinking tabs, 120px minimum and 220px maximum; long names ellipsize intentionally, with full accessible name and a hover/focus disclosure. Count remains visible. Fixed siblings outside the scroller: previous/next scroll controls (only when overflowing), **All canvases · N**, Add and Tab actions. All canvases opens a searchable list of full names/counts, marks the active canvas and allows selection with arrows/Enter/Escape. Add disables at 20 with an explanation. Phone/read-only omits editing controls, not navigation.

Measure the **available canvas header**, after panels. Fold arrange, history, Analysis settings, Export and finally Add into Canvas tools as needed; retain every command there. If the tab budget and remaining toolbar cannot coexist, give tabs their own row. Use a compact active-tab + All canvases treatment below 420px, rather than squeezing tabs to nothing. Keep labels on one line. Preserve roving tab focus, Arrow/Home/End, F2, reorder and move/copy/delete; selection/focus scrolls the active tab into view with `nearest`. Drag reorder needs edge autoscroll and the existing menu alternative; phone swiping scrolls, never reorders. Focus returns to the selected tab after chooser dismissal. Test 1/5/20 tabs, first/middle/last activation, long/duplicate names and all panel combinations.

**Low-zoom focus and return (R03).** When scale is **<0.5**, an unmodified primary click/tap on a card body/header, released within 6 screen pixels of its start, selects that card and flies to frame it. Trigger on release, never pointerdown; dragging, resizing, action buttons, Shift selection, hand/Space pan and pinch must not fly. Enter on the card uses the same path; Shift+Enter retains additive selection. At ≥0.5 keep existing plot interaction. Double-click still opens the inspector; coalesce its focus requests by node id so there is one flight, not a second conflicting zoom.

Capture the pre-focus camera and panel configuration **once per tab**. Honor selection-open and user-closed inspector memory; after the resulting panel layout settles, fit the target's entire card within the usable canvas rectangle, excluding overlays/zoom/minimap, with 32px padding: `s = clamp(min(usableWidth/cardWidth, usableHeight/cardHeight), .05, 1)`, then center. Animate actual camera coordinates/scale for 280ms, cancellable by new user navigation; zero duration under reduced motion. Preserve v0 image-far/live-near/culled behavior. If an oversized card cannot fit at ≥50%, keep it framed and offer “100% to work”; do not force a live renderer below threshold.

Show **Back to overview** beside the zoom controls throughout focused work; it restores that saved camera and panel configuration, without document Undo or autosave. Subsequent focus changes keep the original return point. `Shift+1`/Fit computes a fresh overview and clears the return snapshot; tab switches preserve each tab's return point. `Shift+2` explicitly frames the selected bounds (no-op with none). Escape retains the established dismiss order; it does not silently navigate the camera. On phones the same focus frames above the read-only sheet; its close/Back action restores the pre-focus overview. A background tap closes the sheet only if it was not a pan. No new analysis requests or mutations are implied by navigation.
