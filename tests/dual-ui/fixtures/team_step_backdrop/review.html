Only positive measured values count as detected. At 0%, the separate “Exclude entirely undetected lipids” option still removes lipids absent from every selected sample. A global threshold may remove tissue-specific signals.

2. Handle missing measurements

QRILC assumes left-censored missingness. If that assumption is unsupported, review an alternative with your analyst. Turning imputation off retains missing values; some analysis tools require complete data.
