# Reference-cell presentation assets

These Blender-generated illustrative assets are carried over from Gerardo's existing Lipidomic Explorer guided application. They depict reference neutrophil anatomy, not anatomy reconstructed from lipidomics measurements. Numerical cohort comparisons are displayed separately, from the shared prepared matrix. The cell viewer bundle retains its Three.js MIT license attribution.

The assets and viewer were copied unchanged for this integration; their checksums are recorded in the integration evidence manifest. The R adapter supplies applied normalization and imputation labels without creating another scientific pipeline.
