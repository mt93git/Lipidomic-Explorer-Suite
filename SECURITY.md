# Security Policy

We provide security updates and patches for the following versions of **Global Lipidomics Explorer**:

| Version | Supported          |
| ------- | ------------------ |
| 12.0.x  | :white_check_mark: |
| < 12.0  | :x:                |

---

## Reporting a Vulnerability

The Global Lipidomics Explorer team takes security seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report
Please do **not** report security vulnerabilities through public GitHub issues.

Instead, please report security vulnerabilities via email to:
**`mtricaud.cetri@gmail.com`**

Please include:
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue or a proof of concept.
* Any relevant environment details (OS, R version, browser).

### Response Timeline
* **Initial Acknowledgement**: You will receive an acknowledgement within 48 hours of your report.
* **Assessment & Fix**: We will assess the vulnerability and develop a patch as quickly as possible.
* **Public Disclosure**: A patch and advisory will be released once the fix has been tested and verified across platforms.
